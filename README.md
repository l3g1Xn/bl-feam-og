## Game description

Command a modern combat legion armed with discombobulator beams, lasers, and steel. Deploy minions, cast spells, and read the live math HUD so lethal lines are always visible. Store-exclusive units (including **Dominus Reximus**) expand the arsenal with taunt, immunity, reborn, and board-wide buffs.

### Core features

- Ranked practice (Normal / Hard) with AI opponent (leet-style enemy names)
- Drag-and-drop hand, attack trails, card-specific combat FX
- **10-track** soundtrack (5 LegionX originals + 5 EDM) — tap to play any track
- Hardcore multi-layer battle SFX (power weapons, plasma, beams, war cries)
- Local **LX_SAVE_GAME** auto-save on app close · PIN vault (no accounts / no cloud)
- Graphics quality live: Low → UltraHD (Adreno-first defaults)
- Ticket store for exclusive minions and spells
